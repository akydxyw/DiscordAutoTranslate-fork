## 新功能

- 新增服务器/频道翻译范围：频道规则优先于服务器规则，未命中时使用默认策略；支持默认翻译（黑名单）与默认不翻译（白名单）两种默认策略。私信按频道规则及默认策略判定。
- 翻译范围使用独立规则卡片界面，支持搜索及手动输入 ID 添加；备注仅用于显示和搜索，不参与匹配。
- 自动翻译、项目日志和流式请求改为开关，名称与说明随当前草稿状态更新，切换开关不会自动保存。

## 修复与改进

- API 测试失败时显示具体错误及上游 HTTP 错误原文，不再统一提示“请求失败”。
- “测试连接”不再执行译文防损坏校验，但仍执行完整协议解析并要求非空结果；“测试翻译”和实际翻译保留校验。
- 启用并保存项目日志后，记录 API 测试过程、HTTP 状态和上游错误原文。
- 修改翻译范围备注或规则顺序不再清空译文和在途任务；匹配策略变化仍使旧结果失效。
- 翻译范围入口在加载、保存、同步及不可操作生命周期期间统一禁用。

## 注意事项

- 翻译范围编辑后需先“应用到草稿”，再保存、同步并重启 Discord 才会生效。模块不采集最近目录或真实名称，仅手动添加的 ID 参与匹配。
- 上游 HTTP 错误原文可能包含敏感信息，分享日志或截图前请检查。
