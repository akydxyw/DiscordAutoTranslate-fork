# 渲染、投影与行刷新

宿主签名与字段只维护在版本 [profile](../app/src/main/assets/hook-config/)，新适配流程见 [Hook 适配 Skill](../.agents/skills/discord-hook-adaptation/SKILL.md)。

## 捕获与严格回填

`ContentTree` 按节点出现位置捕获不可改列表、文本分块、内部行数、样式/列表事件和语义容器路径。同一宿主对象出现两次时按两个 occurrence 处理。提取、hash 校验、图标判断和回填共用当前捕获计划；转换时重新捕获当前输入，不把旧生产快照当作仍有效的树，也不为诊断另遍历宿主。

最大语义容器深度为 12，Java 列表包装不加深；路径最多 64，出现位置最多 8192。循环、非法容器或超限整体拒绝，不截断翻译。未改分支保持原对象身份，并校验捕获的列表形状；不深复制 opaque 宿主内部模型。

| 输入部分 | 定位与保留规则 |
|---|---|
| 普通文本 | 使用捕获的文本槽和源边界分配 |
| 格式文本、非 URL 链接标签 | 统一 `<xN>...</xN>` 范围；翻译范围内文字，保留样式及链接上下文 |
| 行内/块代码、提及、时间戳、未知 opaque | 每个非 null 保留叶 occurrence 生成 `<keepN/>`；内部内容不读取、不发送，回填复用原对象 |
| URL、可识别 emoji | 作为有序锚点精确消费，不修改数量、顺序及值 |
| 列表项 | 请求使用 `• `；只消费该项捕获的项目符号前缀，显示仍由原列表节点负责 |

标记缺失、重复、乱序、损坏、保留标记移入样式范围、源文与保留命名空间冲突均拒绝。不得补标记、删除额外 URL 段落、猜测分配或尝试另一种回填解释。fixture 必须显式回带标记，测试辅助代码不能替模型补齐。

边界来自源 LF、BREAK、列表项以及已确认标题的逻辑块分隔。标题 occurrence 切换且缺少真实 LF/列表边界时，统一事件流补一个请求 LF；不向宿主树插入节点，不据此模拟标题布局。普通同行多个文本槽没有精确边界时仍拒绝。连续多槽行按各槽内部行数分配，单个多行槽整块回填；代码内部行数不作为正文边界。

只在所有槽成功对齐、整树重建且保留结构校验通过后提交。请求校验失败不缓存；原生重建拒绝时撤销对应缓存并标记失败，宿主保留原树。公开 data class 使用既定 `componentN/copy` 策略；配置了 `nodeConstructors` 的类型只调用指定签名和参数，不换构造器、不按字段声明顺序猜测、不降为纯文本。

## 回复预览

外层消息绑定捕获引用作用域；`ReplyBinding` 只读取 Loaded 模型、被引用 Message、编辑版本和预览 View 路径。转换参数须匹配引用对象及消息 ID，再以该 ID、编辑版本、规范 Source/hash 和当前 `showingOriginal` 消费已有译文。没有有效规范译文时显示宿主原文，systemContent 不当作消息正文；引用不会独立请求、建状态或注入切换图标。

先在规范原树上对齐译文，再调用同一原生转换器。仅在实际应用译文的引用结果上，对同一个 Drawee Editable 内的 LF/CR/U+2028/U+2029 等长换为空格，然后由 Discord 添加首行 `LeadingMarginSpan`、背景及原生两行省略。不得先压平译文再回填，也不得用普通 `TextView.setText`、字符裁剪或手写省略号覆盖结果。预览登记为规范消息的重放消费者，切换及编辑时重新核对当前绑定。

## 富 Embed

`EmbedBinding` 按 profile 选定唯一输入：`arguments` 直接读模型/ID 参数，或 `accessory` 读指定 accessory。宿主只取 `this` 或指定字段。描述、标题、字段名/值须为真实结构化文本，复用同一捕获、状态及转换链。

每次绑定先撤销该视图旧段登记；绑定作用域内每卡片最多一个图标。嵌套退出恢复原作用域，空卡片、编辑或复用不能重放旧参数。

## Poll

根标题从 profile 指定的 accessory 读取问题和完整答案列表，按稳定答案 ID 包装 Primitive 输入并登记统一翻译；隐藏选项也登记。选项绑定只消费状态并登记显示/重放，不单独发请求。

原生 String setter 仅在同步绑定作用域内、receiver 和原始输入都匹配时替换参数。文本选项改 label 的 `setText`，图片选项仅改图片 View 的 `setContentDescription`，不增加可见字幕。不得修改模型、答案 ID、图片、票数、百分比、选择状态或宿主点击/长按回调。

`PollCardState` 唯一控制整卡显示选择。只有当前标题有图标和切换触摸；标题失败入口重试当前所有失败段。重复绑定和编辑保留卡片选择、替换成员集合；迟到结果不重置选择。选项重放前核对当前槽位、稳定 ID、文本键及成员，避免排序/编辑后套用旧参数。

## 图标与布局

普通正文和 Embed 在原生转换结果尾部注入 `InlineIconSpan`；Poll 在标题注入整卡图标。IDLE 或没有可翻译文本时不显示，回复不显示。进度灰色旋转，译文蓝色，原文灰色，失败红色；点击切换或手动重试。

点击仅通过 profile 指定的宿主原生 span 唯一构造器和统一 callback；不增加备用监听器。模块图标由 `PackageManager.getResourcesForApplication` 解析，每次复制后着色；缺失、复制或着色失败时拒绝注入，不修改共享 Drawable。

`RenderDispatcher` 将原生重放移出布局遍历并核对绑定。`RowRefresher` 按 profile 查 LayoutParams/holder、绑定缓存、所属 RecyclerView 和 adapter observable，清理已配置的绑定早退缓存后通知行更新；布局期间延后执行并按同帧去重。不依赖猜测类名、手工 measure/layout 或直接覆盖 TextView。

设备验证矩阵见 [开发与验证](development.md)。单元测试不能代替真实 Drawee、触摸、RecyclerView、折叠和 Spoiler 布局验证。
